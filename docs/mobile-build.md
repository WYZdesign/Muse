# Mobile builds

Muse ships as a Capacitor wrapper. `capacitor.config.ts` points `server.url` at
`https://muse.wyzdesign.com`, so the native shell loads the production site at
runtime and no web bundle is embedded. `out/` still has to exist for
`cap sync`, which is why the CI job creates a placeholder.

## What exists in the repo

- `android/` with Gradle wrapper 8.14.3, AGP 8.13.0, compileSdk/targetSdk 36,
  minSdk 24.
- `ios/` with the `App.xcodeproj` (the workspace and Pods are generated by
  `npx cap sync ios`).
- `scripts/mobile-build.ps1`, which wraps `cap sync` and the platform build.

## Produce an Android debug APK

Locally you need:

- JDK 21
- Android SDK with platform 36 and build-tools 36.0.0
- `ANDROID_HOME` set

```
npm ci
mkdir -p out && printf '<!doctype html><title>Muse</title>' > out/index.html
npx cap sync android
cd android && ./gradlew assembleDebug
# android/app/build/outputs/apk/debug/app-debug.apk
```

Or run `pwsh -File scripts/mobile-build.ps1 -Platform android`, which checks
for JDK 21, `ANDROID_HOME`, and platform 36 before building.

## Produce an iOS simulator build

Needs macOS with Xcode and CocoaPods.

```
npm ci
mkdir -p out && printf '<!doctype html><title>Muse</title>' > out/index.html
npx cap sync ios
cd ios/App && xcodebuild -project App.xcodeproj -scheme App \
  -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

Or run `pwsh -File scripts/mobile-build.ps1 -Platform ios` on macOS.

## Not done, and why

- **Signing.** No Android keystore or Apple signing identity is in this repo.
  Store builds need those plus the store accounts. Debug APK and simulator app
  are installable but not distributable.
- **RevenueCat keys.** `REVENUECAT_IOS_API_KEY` and
  `REVENUECAT_ANDROID_API_KEY` are not present in the vault or the Vercel
  project, so in-app purchases are not configured. Until those keys exist and
  products are created in the RevenueCat dashboard, paid features inside the
  native apps cannot work.
- **Store assets.** Screenshots, privacy manifests, and store listings are not
  part of this pass.
- **Real-device performance.** Nothing here substitutes for measuring on a
  mid-range Android phone.
