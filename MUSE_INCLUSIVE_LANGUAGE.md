# MUSE_INCLUSIVE_LANGUAGE.md — Inclusive Terminology Standard

> **PURPOSE:** Muse is for **everyone** who wants to shoot, book, or collab — from complete
> first-timers who have never booked a session to polished veterans with hundreds of bookings.
> This document sets the terminology standard so every screen, card, badge, email, and doc makes
> both ends feel equally comfortable to connect, communicate, and spend. **Nothing should imply
> "pros only" or shame inexperience.**
>
> **Applies to:** all UI copy, headtext, empty-states, badges, tooltips, docs (MUSE_*.md,
> HANDOVER.md), emails, notifications, prompts, and the boardroom pack. `<user>` = anyone at any
> level.

## The Rule of Thumb
Every message must read as "wherever you're starting, this is for you." Borrow from neutral,
level-agnostic framing. Never gate the tone behind experience.

## Do / Don't Replacement Table
| Avoid (sounds exclusive / expert-coded) | Use (inclusive, level-neutral) |
|--------------------------------|--------------------------------|
| "Professionals only" / "Pros only" | "Open to all levels" |
| "Never booked before?" (shame-adjacent) | "New to sessions? Easy — here's how it works" |
| "Newbies / amateurs" | "First-time creatives", "getting started" |
| "Veteran / expert / guru" | "Experienced", "seasoned", "established" |
| "Beginner-friendly" (implies the rest isn't) | "Everything is bookable at your pace" |
| "Post a brief" (industry jargon) | "Share a project", "Start a project" |
| "Book a session" (transactional-only) | "Book a session", "Reserve time together" |
| "Collaborate with pros" | "Collaborate with creators at any level" |
| "You need 50+ bookings to qualify" | "Everyone starts somewhere" |
| "TFP / Paid" (jargon-only) | "Trade / Pay", with a tooltip explaining each |
| "Verified Pro" (exclusive) | "Identity verified", "Verified member" |
| "NSFW" as a hard wall | "18+ content", with the reveal gate (kept, by policy) |

## Terminology That Must Always Be Level-Neutral
- **Sessions**: frame as "book time / a session" — never "hire a professional" only.
- **Briefs**: frame as "share a project / open call" for anyone to respond.
- **Reviews / ratings**: "your first project" not "your first client."
- **Quests / XP / streaks**: reward logging in and *any* progress, not just paid bookings.
- **Studios**: "browse local studios in the LA area" — inviting, not "for industry only."
- **Trust / verification**: verify identity and age, never imply a "career threshold."

## Where It's Already Applied (this pass)
- Sessions browse descriptor → **"Find a session, book it, and pay securely."**
- Sessions LA studios descriptor → **"Browse local studios in the LA area"**
- BTS intro copy → level-neutral "real-time shot of your creative process… everyone starts somewhere."
- Discovery, quests, and empty-states use neutral verbs (start, share, find, launch).

## Boardroom / Product Consistency
1. **Pitch (MUSE_PITCH_EXPLAIN.md)** — keep the audience line "anyone who wants to shoot or
   collab, whatever the experience" out front.
2. **Gaps (MUSE_GAPS_ADJUSTMENTS.md)** — money/experience gaps stay about the *flow*, never the
   user's *level*.
3. **Money (MUSE_MONEY.md)** — the 15% take + tiers apply to everyone; never gate a tier behind
   "has bookings already." Muse Pro = "unlock more," not "unlock professional."
4. **Safety/Transparency** — disclosure/escrow/check-ins are framed as *for everyone's comfort*,
   not "protection for professionals."

## Checklist Before Shipping Any New Copy
- [ ] No "pros only / newbies / experts / gurus" anywhere.
- [ ] Empty states say "get started" not "you haven't done X yet."
- [ ] Any jargon (TFP, brief, escrow) has a tooltip or plain-language substitute.
- [ ] Both a first-timer and a veteran would read it as welcoming them.
